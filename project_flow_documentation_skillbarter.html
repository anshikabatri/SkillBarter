1. Project Overview & Structure

This repository contains two main parts:

  • Backend: `skillbarter/` — Spring Boot application (Maven)
  • Frontend: `frontend-main/skillbarter-v2/` — Angular app (package.json, Angular 17-style)

Top-level layout

/ (workspace root)
├─ frontend-main/skillbarter-v2/ (Angular app)
├─ skillbarter/ (Spring Boot backend)
├─ uploads/ (static/uploads)
├─ README.md

2. Technology Stack

Backend

  • Spring Boot (Maven)
  • Java 17+
  • Spring Data JPA
  • H2 (dev) / MySQL (prod) typical
  • JWT-based auth (likely)

Frontend

  • Angular (project in frontend-main/skillbarter-v2)
  • TypeScript, RxJS
  • HttpClient, Guards, Interceptors
  • Chatbot & realtime services present

Dev / Ops

  • Dockerfile in `skillbarter/`
  • Maven wrapper (`mvnw`, `mvnw.cmd`)

3. Backend (skillbarter/)

Key files and structure (inside skillbarter/src/main):

src/main/java/com/... (package tree)
├─ controllers
├─ service
├─ repository
├─ entity
├─ resources/application.properties

Build & artifact

Maven builds a jar; `target/` contains the packaged artifact. Use `mvnw spring-boot:run` to run locally.

Common request flow

  1. HTTP request → DispatcherServlet → Controller
  2. Controller → Service layer → Repository (JPA)
  3. Service returns DTO → Controller returns ResponseEntity

4. Frontend (frontend-main/skillbarter-v2/)

Angular app entry: `src/main.ts` and `src/app/` (components, services, pages). Look for `app.component.ts`, `app.routes.ts`, and `services/api.service.ts`.

Features present

  • Topbar / Sidebar components for layout
  • Chat and chatbot components (chatbot.component.ts)
  • Auth service and HTTP interceptor for token injection
  • Realtime chat services (`realtime-chat.service.ts`, `ws-chat.service.ts`)

Routing & guards

App uses route guards (auth.guard.ts) to protect pages and interceptors to add JWT tokens.

5. Authentication & Security

The project uses token-based auth patterns on the frontend (`auth.service.ts`, `auth.interceptor.ts`). The backend likely exposes `/api/auth/*` endpoints and uses a Jwt filter similar to typical Spring Boot setups.

Key frontend places:
- `frontend-main/skillbarter-v2/src/app/services/auth.service.ts`
- `frontend-main/skillbarter-v2/src/app/services/auth.interceptor.ts`

6. Chat / Real-time / AI pieces

Files to review for chat/AI functionality:

  • `frontend-main/skillbarter-v2/src/app/components/chatbot/` — chatbot UI
  • `frontend-main/skillbarter-v2/src/app/services/realtime-chat.service.ts` — realtime helper
  • `frontend-main/skillbarter-v2/src/app/services/ws-chat.service.ts` — WebSocket-based chat
  • `frontend-main/skillbarter-v2/src/app/services/gemini.service.ts` — external AI / LLM integration wrapper (name suggests Gemini usage)

These indicate a hybrid architecture where messages can be sent to a server or proxied to an LLM service.

7. Database & Entities

Backend contains `entity` and `repository` packages. Inspect `skillbarter/src/main/resources/application.properties` and `target/classes` for runtime configuration.

Look for:
- `skillbarter/src/main/java/.../entity/` (JPA entities)
- `skillbarter/src/main/java/.../repository/` (Spring Data repositories)

9. Quick Start & Build

Backend (Windows / PowerShell)

cd skillbarter
./mvnw spring-boot:run
# or build: ./mvnw -DskipTests package

Frontend

cd frontend-main/skillbarter-v2
npm install
npm run start
# or with Angular CLI: ng serve

Docker

# Dockerfile available under `skillbarter/` — build a container for backend
docker build -t skillbarter-backend ./skillbarter
