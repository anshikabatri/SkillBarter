1. 🏗️ Project Overview & Architecture

What is CoachMetrics V2?

CoachMetrics V2 is a Mentor Activity Management System that enables coaches to manage mentors, track their training progress, schedule sessions, and generate reports. The system includes an intelligent agent feature that uses natural language processing to create sessions and update tracker data.

Key Roles

👔 ADMIN

  • Manage coaches
  • View all mentors
  • Generate reports
  • View system-wide dashboard
  • Manage departments & verticals

🎓 COACH

  • Manage their mentors
  • Schedule coaching sessions
  • Track mentor progress
  • Use AI Agent for quick updates
  • View personal dashboard

Request Flow

HTTP Request arrives

2

Filter extracts JWT token from Authorization header, validates it, and sets SecurityContext
3
SecurityConfig validates

4
Controller receives request
@RestController method handles the request with @RequestBody/@PathVariable parameters
5
Service processes business logic
Service layer handles validation, calculations, and orchestrates repository calls
6
Repository accesses database

Backend Security Implementation

// JwtAuthFilter.java - Intercepts every request @Override protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) { // 1. Extract JWT from Authorization header String authHeader = request.getHeader("Authorization"); if (authHeader == null || !authHeader.startsWith("Bearer ")) { filterChain.doFilter(request, response); return; } String jwt = authHeader.substring(7); try { // 2. Extract email from token String email = jwtService.extractUsername(jwt); if (email != null && SecurityContextHolder .getContext().getAuthentication() == null) { // 3. Load user details UserDetails ud = customUserDetailsService .loadUserByUsername(email); // 4. Validate token if (jwtService.isTokenValid(jwt, ud)) { // 5. Set authentication in context UsernamePasswordAuthenticationToken auth = new UsernamePasswordAuthenticationToken( ud, null, ud.getAuthorities()); SecurityContextHolder.getContext() .setAuthentication(auth); } } } catch (Exception e) { System.out.println("JWT error: " + e.getMessage()); } filterChain.doFilter(request, response); }

Frontend JWT Interceptor

// jwt.interceptor.ts - Adds token to all requests @Injectable() export class JwtInterceptor implements HttpInterceptor { constructor(private auth: AuthService) {} intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> { // 1. Get token from localStorage const token = this.auth.getToken(); // 2. Clone request and add Authorization header if (token) { req = req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }); } // 3. Handle 401 errors return next.handle(req).pipe( catchError((err: HttpErrorResponse) => { if (err.status === 401) { this.auth.logout(); // Clear token and redirect } return throwError(() => err); }) ); } }

Route Protection with AuthGuard

// auth.guard.ts @Injectable({ providedIn: 'root' }) export class AuthGuard implements CanActivate { constructor(private auth: AuthService, private router: Router) {} canActivate(route: ActivatedRouteSnapshot): boolean { // 1. Check if user is logged in if (!this.auth.isLoggedIn()) { this.router.navigate(['/login']); return false; } // 2. Check role-based access const roles: string[] = route.data['roles'] ?? []; if (roles.length && !roles.includes(this.auth.getRole())) { // Redirect to appropriate dashboard this.router.navigate([ this.auth.isAdmin() ? '/admin/dashboard' : '/coach/dashboard' ]); return false; } return true; } }

6. 🤖 Agent Feature - Natural Language Processing

Overview

The Agent feature allows coaches to create sessions and update mentor tracking data using natural language. It parses text like "virtual session with Arun Kumar today from 10am to 11:30am" or "update 1 hr virtual for Arun, Divya and Meena on 2nd Apr".

Agent Flow

1
User types natural language text
In AgentChatComponent, user enters text like "update 1 hr for Arun on 2nd Apr"
2
Frontend sends to /api/coach/agent/parse
AgentApiService.parse(text) makes POST request
3
AgentController receives request
Controller forwards to AgentService.process()
4
AgentService detects intent
Analyzes text to determine: NEW_SESSION or UPDATE_TRACKER
5
Extract entities using regex
• Mentor names (matches against coach's mentors)
• Date parsing (today, tomorrow, specific dates)
• Time parsing (10am, 11:30am)
• Duration (1 hr, 1.5 hrs)
• Mode (virtual, in person)
6
Build confirmation message
Returns parsed data with: date, hours, mode, mentor(s), missing fields
7
Frontend displays confirmation
Shows parsed data in chat bubble with "Confirm & Save" button
8
User confirms → POST /api/coach/agent/save
Same text sent with autoSave=true to actually create/update records

Intent Detection Logic

// AgentService.java private String detectIntent(String lower) { // Check for update keywords at start if (lower.startsWith("update ") || lower.startsWith("mark ") || lower.startsWith("record ") || lower.startsWith("log ")) { return "UPDATE_TRACKER"; } // Check for time range (indicates new session) boolean hasTimeRange = lower.matches( ".*\\d{1,2}(am|pm|:\\d{2}).*to.*\\d{1,2}(am|pm|:\\d{2}).*"); // Check for update-related words boolean hasUpdateWord = lower.matches( ".*\\b(update|mark|record|done|completed|happened)\\b.*"); if (hasUpdateWord && !hasTimeRange) { return "UPDATE_TRACKER"; } if (lower.contains("tracker") || lower.contains("weekly connect")) { return "UPDATE_TRACKER"; } return "NEW_SESSION"; }

Bulk Update Support

The agent can handle multiple mentors in a single command:

// Input: "update 1 hr virtual for Arun, Divya and Meena on 2nd Apr" // AgentService detects multiple mentor names: List<Mentor> mentionedMentors = findAllMentors(text, lower, myMentors); if (mentionedMentors.size() > 1 && "UPDATE_TRACKER".equals(intent)) { return processBulkUpdate(text, lower, autoSave, coach, mentionedMentors, res); } // Bulk update will: // 1. Parse common data (hours, mode, date) // 2. Apply to all mentioned mentors // 3. Update their MentorConnect records for the specified week // 4. Return success count and individual results

Date & Time Parsing

// Supports multiple formats: // - "today" → current date // - "tomorrow" → current date + 1 // - "2nd Apr" → April 2, 2026 // - "15 Mar" → March 15, 2026 // - "10am" → 10:00 // - "11:30am" → 11:30 // - "2pm" → 14:00 private LocalDate parseDate(String lower) { LocalDate now = LocalDate.now(); if (lower.contains("today")) return now; if (lower.contains("tomorrow")) return now.plusDays(1); // Match patterns like "2nd Apr", "15 Mar", etc. Pattern p = Pattern.compile( "(\\d{1,2})(st|nd|rd|th)?\\s+(jan|feb|mar|apr|...)"); Matcher m = p.matcher(lower); if (m.find()) { int day = Integer.parseInt(m.group(1)); String mon = m.group(3); int month = monthToNum(mon); return LocalDate.of(2026, month, day); } return now; }

7. 👥 Mentor Management Flow

Mentor Lifecycle

1
Coach creates mentor
POST /api/coach/mentors with MentorRequest containing:
• Full name, Associate ID
• Department, Vertical, Cohort
• Batch duration (weeks)
2
System generates MentorConnect records
Automatically creates 14 weekly tracker records (MentorConnect entities)
Each with: week number, date range, hours=0, mode=PENDING
3
Coach tracks weekly progress
Views mentor tracker showing all 14 weeks
Updates hours, mode (VIRTUAL/IN_PERSON/PENDING) for each week
4
Progress calculation
System calculates:
• Total hours logged
• Weeks completed
• Training status (ONGOING/COMPLETED/PAUSED)

Mentor Entity Structure

@Entity @Table(name = "mentors") public class Mentor { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; private String fullName; private String associateId; @ManyToOne @JoinColumn(name = "coach_id") private User coach; // Coach who manages this mentor @ManyToOne @JoinColumn(name = "department_id") private DepartmentEntity department; @ManyToOne @JoinColumn(name = "vertical_id") private VerticalEntity vertical; private String cohort; private Integer batchDurationWeeks; private LocalDate startDate; @Enumerated(EnumType.STRING) private TrainingStatus trainingStatus; // ONGOING, COMPLETED, PAUSED @OneToMany(mappedBy = "mentor", cascade = CascadeType.ALL) private List<MentorConnect> weeklyConnects; // 14 weeks @OneToMany(mappedBy = "mentor", cascade = CascadeType.ALL) private List<CoachSession> coachSessions; }

MentorConnect (Weekly Tracker) Entity

@Entity @Table(name = "mentor_connects") public class MentorConnect { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private Long id; @ManyToOne @JoinColumn(name = "mentor_id") private Mentor mentor; private Integer weekNumber; // 1-14 private String weekDateRange; // "19 Jan - 23 Jan" private LocalDate weekStartDate; private LocalDate weekEndDate; private Double hoursLogged; // 0.0 to N @Enumerated(EnumType.STRING) private MentorConnectMode mode; // VIRTUAL, IN_PERSON, PENDING private String notes; }
